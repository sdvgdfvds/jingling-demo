# 精灵demo：崩坏·因缘精灵核心战斗 Demo（Unity）

基于 **Unity 6000.5.10f1**（通过桌面 Unity Hub）的最小可行自走棋战斗 Demo。

仓库正在分批上传。首批包含脚本、场景、配置和战斗数据；美术、音频等较大素材将在后续批次加入。首批克隆后尚不能完整还原本地画面。

## 如何打开

1. 启动 Unity Hub。
2. 添加克隆后的项目文件夹。
3. 编辑器选：**6000.5.10f1**
4. 打开场景：`Assets/Scenes/BattleDemo.unity`
5. 点击 Play

本地已有的 `OpenDemo.bat` 使用原电脑的绝对路径，因此不包含在仓库中。

## 操作说明

1. 底部精灵池选中单位
2. 棋盘蓝区放我方、红区放敌方；可拖拽调整
3. 右上角点「开始战斗」
4. 战斗中点击右侧 **心象技能** 三个头像（冰伤 / 增益 / 治疗），再点目标单位释放
   - 冰伤：敌方（伤害 + 短眩晕）
   - 增益：我方（攻击提升）
   - 治疗：我方（回复生命）
   - 三技能独立冷却；施放时镜头聚焦，播放抠黑技能动画（保留完整音频）
5. 结束后点「重新布阵」
